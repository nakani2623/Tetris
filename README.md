# Tetris

A Tetris game featuring a Java game engine and a JavaFX user interface, built with Gradle.

## Build and Run

### Requirements

- JDK 17 or later
- Gradle Wrapper is included, so no separate Gradle installation is needed.

### Clone the Repository

```bash
git clone https://github.com/nakani2623/Tetris.git
cd Tetris
```

### macOS / Linux

Build the project:

```bash
./gradlew build
```

Run the game:

```bash
./gradlew :app:run
```

### Windows

Build the project:

```powershell
.\gradlew.bat build
```

Run the game:

```powershell
.\gradlew.bat :app:run
```
